# Escala de Grandes Eventos – app do policial

Tela do app (PWA) publicada no GitHub Pages. Os dados ficam na planilha do planejamento e são lidos pela API do Google Apps Script; este repositório não contém dados de policiais.

- `index.html`: o app
- `manifest.webmanifest` e ícones: instalação na tela inicial
- `sw.js`: abre o app sem internet (a escala fica salva no celular)
